# Data provenance

This capsule uses **no external raw data files**. The external-validation
reference values (peak plasma concentration Cmax, time-to-peak Tmax, dose,
sampling site) are digitized summary pharmacokinetic parameters from
peer-reviewed clinical studies of local-anesthetic administration. They are
embedded, with full per-record source citations, in
`code/validation_data.py`. See the reference list at the top of that file for
the primary sources of every record.
